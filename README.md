# PruebaBackend

Comandos:
1. Dar permisos de ejecución (solo la primera vez)
```bash
chmod +x mvnw
```
2. Ejecutar la aplicación
```bash
./mvnw spring-boot:run
```
3. Compilar el proyecto
```bash
./mvnw compile
```
4. Ejecutar las pruebas
```bash
./mvnw test
```
5. Limpiar y compilar
```bash
./mvnw clean compile
```
6. Generar el JAR ejecutable
```bash
./mvnw clean package
```
